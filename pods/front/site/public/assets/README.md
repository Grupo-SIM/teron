# Assets do site

## Marca Teron

As fontes oficiais ficam em `brand/`:

- `logo-horizontal-dark.svg` e `logo-horizontal-light.svg` — wordmarks para fundos claros e escuros
- `logo-stacked-dark.svg` e `logo-stacked-light.svg` — composições empilhadas
- `icon-dark.svg` e `icon-light.svg` — símbolos para fundos claros e escuros

`teron-email-logo.png` é exportado em 2x a partir do wordmark horizontal claro,
pois clientes de e-mail não têm suporte consistente a SVG. Os arquivos
`teronwhite.svg`, `LOGO TERON  - BRANCA.svg`, `logo-nav.png`, `logo-footer.png`,
`logo-mark.png` e `teron-icon.png` continuam atualizados para compatibilidade
com URLs antigas.
